# Strays

See everything running in the background on your Mac — listening ports, dev
servers, Docker containers, brew services, and the processes your AI coding
agents left behind — and stop it in one click.

> Work in progress. A full README lands with the first release.

## Building

```bash
brew install xcodegen
make build   # generate the Xcode project and build Strays.app
make test    # run the StraysCore unit tests
make run     # build and launch (Strays lives in the menu bar)
```

Requires macOS 14+ and Xcode 16+.
